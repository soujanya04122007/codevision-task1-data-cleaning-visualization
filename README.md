Task 1: Data Cleaning & Visualization 📊

Welcome to the Task 1 repository for my Machine Learning Internship at IncodeVision!

📌 Project Overview

This project focuses on data cleaning, exploration, analysis, and visualization using the Titanic dataset.

The goal is to clean and analyze the raw dataset and represent important patterns and relationships through different visualizations.

🎯 Objectives

- Load and understand the Titanic dataset.
- Perform basic data cleaning and preprocessing.
- Explore the dataset and its features.
- Analyze survival-related information.
- Create meaningful statistical visualizations.
- Identify patterns and relationships within the data.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

🔍 Project Process

1. Data Loading

The Titanic dataset is loaded using Pandas for further analysis and processing.

2. Data Cleaning

The dataset is examined for missing values and other data-related issues. Basic preprocessing is performed to prepare the data for analysis.

3. Data Exploration

The dataset is explored to understand the available features, distributions, and survival information.

4. Data Visualization

Different visualizations are created using Matplotlib and Seaborn to understand the dataset more effectively.

The project includes:

- Boxplot – Used to visualize the distribution and identify potential outliers.
- Heatmap – Used to examine correlations between numerical variables.
- Histogram – Used to understand the distribution of data.
- Survival Count Plot – Used to visualize the number of passengers who survived and did not survive.

📊 Visualizations

Boxplot

The boxplot provides a statistical view of the data distribution and helps identify possible outliers.

Heatmap

The heatmap represents correlations between numerical variables in the dataset.

Histogram

The histogram shows the distribution of selected numerical data.

Survival Count

The survival count visualization compares the number of passengers who survived with those who did not survive.
